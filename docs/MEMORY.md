# 记忆

**记忆在主链路上，不是插件。** 每次说话之前无条件先过一遍召回，
把该记得的直接摆在模型面前。

做成工具的话（让模型「需要时自己去查」）有个根本问题：
**它得先意识到自己该记得什么** —— 可绝大多数时候它根本不知道自己忘了。

## 这里自带的那份

很轻，一个文件（`core/memory/recall.py`），三段拼装：

```
〔你是谁〕      人设 —— 决定它用什么口吻读下面这些
〔翻出来的旧事〕 跟这句话有关的旧事
〔最近说的话〕   上下文 —— 放最后，离得越近抓得越牢
```

存储那边（`core/store/sqlite.py`）做检索。**中文按 2-gram 切**，英文按词切，
按命中片段数排序。

> ★ 为什么不用 SQLite 的 FTS5：它默认分词器不切中文，一整句会被当成一个词。
> 只用它的话，人问「豆子最近怎么样」永远翻不到「他的猫叫豆子…」——
> 而界面上一切正常，AI 只是「什么都不记得」，看起来像模型笨，不像检索坏了。
> 这是这个项目最难发现的一种坏法，所以现在两条腿走：切片 ＋ LIKE，慢但不漏。

**够用到什么规模**：个人用，几千条以内没问题。上万条要上向量检索。

## 空的时候

新装那天记忆是空的。那些页面写的是「还没有东西，你们才刚认识」，
不写「暂无数据」，也不灌假数据把界面填满。

**这是起点，不是缺陷。** 想先看看满了什么样：`python -m core.seed`。

## 不想用这份实现

存储和召回是**两个独立的接口**（`core/store/base.py` 和 `core/memory/recall.py`），
换掉任何一个都不影响别的。接口很小，故意的 —— 方法越少，你自己写一个就越容易。

要接别人的记忆系统，下面这些是可以去看的方向。**我们没有逐个用过**，
列在这儿是给你省搜索的时间，不是背书：

| 方向 | 找什么 |
|---|---|
| 托管的记忆层 | 搜 `mem0`、`Zep` —— 提供记忆抽取、检索、时序图谱的服务/库 |
| 有状态的 agent | 搜 `Letta`（原 MemGPT）—— 把「上下文管理」当成 agent 的一等公民 |
| 记忆连续性 | [`Pyruslili/Nocturne-Memory-Core`](https://github.com/Pyruslili/Nocturne-Memory-Core)（MIT）—— 我们的「近场日记」那一层就是从它学的 |
| 向量检索 | 上万条之后需要。`sqlite-vec`、`Chroma`、`LanceDB` 都能塞进现在这个存储接口里 |
| 自己写 | 实现 `Store` 的六个方法就行。第一版可以就是一个 JSON 文件 |

**换掉之后要守住的只有一条**：召回结果得在**说话之前**拼进 system prompt，
而不是等模型自己来问。那是这套东西之所以像「记得你」而不是「查得到」的原因。

## 记忆的形状

```jsonc
{ "content": "他的猫叫豆子，橘色，六岁。",
  "layer": "L2",          // L1 最近的 / L2 沉下来的事实 / L3 关系的地基
  "tags": ["豆子"],
  "ts": 1756400000 }
```

`layer` 是**召回时决定读多少**用的，不是重要性排名。
一条 L1 可能比 L3 重要得多 —— 它只是还没沉下去。

## 蒸馏（把对话变成记忆）

内置，在 `core/distill.py`。四段，缺一段库就会越长越脏：

| 段 | 做什么 | 规矩 |
|---|---|---|
| 提取 | 攒够轮数（出厂 20 轮，0 = 关掉）就在后台拿最近的对话让模型提候选，一次最多 3 条 | 只落「潜在」，不直接进库；绝不挡住正在说的这一轮 |
| 审批 | 潜在记忆页里一条条 keep / drop；keep 错了可以 unkeep 撤回 | 默认人点头才入库；`auto_keep` 可开，默认关 |
| 去重 | 新候选跟老记忆按 2-gram 字面重合算，到 0.75 就标「疑似跟第几条重了」 | 只标不合并：合并不可逆，语义近不等于同一件事，所以不用向量 |
| 升层 | 被召回过 5 次的 L1 升 L2，15 次的 L2 升 L3 | 升层不改内容，所以不问人 |

阈值走 `POST /api/distill/config` 改（出厂值在 `core/distill.py` 顶上）；接口见 [docs/API.md](API.md) 的「蒸馏」一节（`/api/distill`、`/api/latent`）。
手动记的入口还在（记忆页那个输入框），蒸馏是加在旁边的，不替代它。
