# 全功能审阅 · 六档归位

每一个功能都归进六档之一。原则：**能合法再分发而且已经做好的，就直接给完整实现**；
上游明显更完整才诚实推荐；只完成前端的就只说前端；不想要的可以彻底隐藏，但资料不删、以后能恢复。

| 档 | 含义 |
|---|---|
| **①内置** | 装好就在用，不用动手 |
| **②魔改懒人版** | 我们的实现直接给（跟①一样能用），但它学过别人 —— 出处在 UPSTREAM |
| **③指路原仓库** | 想要原作业的去上游装，装配单里有路 |
| **④只要前端** | 界面＋接口契约＋诚实待接，后端自己写 |
| **⑤兼容服务** | 仓内有适配，用户自备合法服务、账号或 key |
| **⑥完全隐藏** | 普通入口全部消失；资料不删、可恢复，也不生成假工作单 |

## 聊天与记忆（① 内置）

聊天（流式/分句/思考链/刷新续播）· 记忆（召回注入/总览/分层/增删）· 人设（双方）·
聊天记录按天翻 · 收藏（带上文）· 热力图月历 · 全局搜索 · 藏一句/删一轮 ·
导入导出搬家 · 引擎切换（换个脑子）· 想多深 · 头像上传（中心裁剪）· 返回手势

## 记事与生活（① 内置，homelife / homeplus 包）

信（AI 会写信进箱）· 他的日记 / 我的日记 · 碎碎念 · 空间（发帖，**AI 楼中接话**）·
时间线 · 心情六维（**AI 自己记涨落和原因**）· 梗库 · 玩具厅（**AI 写小玩意上架**）·
日历与纪念日（AI 也能记）· 相册 · 我在哪 · 正在听 ·
人设改动历史 · **记忆字云**（总览页那片会飘的字符云——算法出自 ThreeUI Study 08，MIT，
连线/深度/拾取是这家新增；数据口径跟四层列表对账；**满血/实时**两档 ——
满血把真记忆克隆铺满画布纯好看、点谁出来的都是真记忆，实时一条一符，工具栏一键切）·
**枫叶水面开屏**（纯原创，程序化秋溪＋滑动解锁）· 颜文字抽屉（这家自己发布的开源组件，325 枚）

## 共读（② 轻量懒人版 + ③ 完整上游，reading 包）

传 txt 自动切章 → 读 → 划句批注 → **就这一章跟它聊**（带原文上下文）。
本仓需求较轻，只做轻量 txt 阅读；完整电子书体验推荐 [Readest](https://github.com/readest/readest)。
记忆分层里「近场日记」的思路学自 Nocturne-Memory-Core（MIT，见 UPSTREAM）。

## 通话（⑤ 兼容服务，call 包）

你说（流式转写）→ 当前聊天模型回答（带人物、启用记忆和本通上下文）→ 语音合成。
**ElevenLabs** 与**豆包端到端全双工**的服务端适配都在仓内；功能包页保存 key 只代表“已配置”，
第一次真实拨号成功后才算供应商验通。没有 key 时错误态必须明确，不能显示假通话成功。

## QQ（③ 指路 + 我们的桥接头，qq-napcat 包）

在岗状态/扫码/重登：贴 NapCat 口令就通。NapCat 本体是别人的开源项目（指路）。
消息桥（QQ 里真聊天）还没剥：契约在包卡上。

## 音乐一起听（④ 只要前端 + ③ 完整上游）

这套前端保留，后端契约在 docs/API.md（musicSearch/Stream/Lyric…）。因本仓需求很轻，
完整一起听推荐 [music-together](https://github.com/Yueby/music-together)；本仓不打包非官方音源接口。

## 共看链接与纯文字旅行（① 内置）

书房里小红书 / GitHub 入口把链接带回同一聊天账本，当前模型能围绕链接继续聊；空间里的链接仍进空间记录与评论。
它不是同步浏览器，不画一个假的“双人同屏”。旅行票根可以由人手写或由 AI 的工具写入同一 `trips` 表，
只用文字，不要求生图或多模态模型。

## Engawa 阅读侧廊（② 内置适配 + 固定 MIT 上游）

设置 › 功能包里一键安装固定提交；运行时只落在本机 `.runtime/`，不进入 Git。
网页、RSS、书架、今晚的天空、每日诗画、NASA 天文图和 arXiv 共 12 项 MCP 工具会同时交给 AI，
书房里的檐廊也能直接调用。它不需要模型 key；网络或上游失败时显示真实错误，不填演示内容。

## 钓鱼（③ 指路）

鱼篓图鉴的界面在。鱼的存档来自一个外部小游戏（见装配单）——想要就去装那个游戏。

## 待接后端的（④，入口标「待接」）

校准提议 —— 界面在、契约在 docs/API.md，后台那条流水线还没有，入口老实标待接。
健康数据（iPhone 快捷指令推送那类）同此。潜在记忆和记忆审批已经接上蒸馏，见 docs/MEMORY.md。

## 不进入公开发行物的（隐私/安全边界，见 EXCLUDED.md）

用户数据、密钥、推送订阅、上传文件、受限桌宠素材和没有再分发许可的材料不会进入发行物。
正常功能不会因为“独有”而被藏起来。

## AI 的外接工具（MCP）

设置 › 功能包 › **AI 的外接工具**：登记一条 MCP server（跟 Claude 的 .mcp.json 同格式），
AI 当场长出它的工具 —— 钓鱼小游戏、日历、任何 stdio server，聊天里说一声它就会用。
**命令以你的身份运行，只贴你信得过的**；AI 只能用已登记的，不能自己添加 ——
它想要新工具会写进装配单等你点头。用本机 CLI 引擎的更简单：CLI 自己就吃 `.mcp.json`。
