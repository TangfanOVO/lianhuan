# 分层：两把尺子

这个项目不是「一个大包让你自己裁」。它一开始就是分开的，**装的时候只把你勾中的复制进去，
没勾的根本不下载。**

拆的时候用两把**互相垂直**的尺子。搞混了就会打架——常见的错误是把
「功能」「前端资产」「接口」并成一列，那三样根本不是一个维度。

---

## 尺子 A · 纵向：你要「能用」，得拿什么

```
① 壳     PWA 外壳、路由、主题、导航、设置、导入导出
② 引擎   接什么模型说话（本机 CLI / API / 你自己的后端）
③ 记忆   人设 + 召回 + 注入 + 落库
④ 功能包 共读、出门走走、日历健康、通话、桌宠…
```

**①②③ = 内核。** 装了就能开聊。
**④ 一个都不装也能聊天。** 完整仓默认附带可用的本地功能包；取件器可按需要裁成更小的组合。

### 关于「记忆」——它是三件事，别混

| | 可不可选 | 说明 |
|---|---|---|
| **位置**（在不在主链路上） | **不可选** | 每次说话前都要过它。没有它，这就是个普通聊天壳 |
| **实现**（谁来存、怎么召回） | **可选** | 用自带的这套，或接你自己的（mem0 / Zep / 自己写的），或纯浏览器本地 |
| **内容** | **一开始是空的** | 你第一天什么都没有，聊着聊着长出来。**这是起点，不是缺陷** |

所以：新装的人**看到的就该是空的**。那些记忆页不写「暂无数据」，
写的是「还没有东西，你们才刚认识」。空态是第一印象，比满的那页更要紧。

想先看看满了是什么样 → 打开 demo 开关，会灌一份**虚构**的种子数据（不是任何真人的）。

## 尺子 B · 横向：你只想要「某块料」，能单独拿什么

```
底座   token · 两套配色（纸／夜）· 一键换 12 色 · 前景色对比度自动算 · 字 · 动效规格 · 换脸机制
 └ 材质   撕边纸 · 格纹胶带 · 票根 · 明信片（航空斜条＋齿孔＋盖销）· 标本卡 · 折起来的日记
    └ 物理   水面待机 · 丝线叠卡（挂在绳上会飘）· 字云
       └ 零件   滑上来的二级页 · 抽屉 · sheet · 弹出菜单 · 全局搜索 · 热力图月历 · 按下回弹
          └ 页面   聊天页 · 记忆页 · 书房 · 日记 · 时间线 …
```

**每层只依赖它下面那层，不依赖上面。** 所以：

| 你想要 | 拿什么 | 要碰后端吗 |
|---|---|---|
| 只喜欢这套配色 | 底座 | 不用 |
| 只喜欢那些纸和胶带 | 底座＋材质 | 不用 |
| 只喜欢会飘的叠卡 | 底座＋材质＋物理 | **不用** |
| 想要记忆那套界面 | 底座＋材质＋物理＋零件＋记忆页 | 要一份 API 契约（mock 先顶着） |

## 两把尺子交叉：每个功能包三个面，多种装法

每个可选功能包切成三个面：

- **前端** —— 界面 ＋ 交互
- **契约** —— API schema ＋ 一份能跑的 mock server
- **后端** —— 我们这边的实现

装配清单能表达这些状态：

| 选 | 拿到什么 | 给谁 |
|---|---|---|
| **不装** | 什么都不下载，界面上连入口都没有 | **默认** |
| 只要契约 | schema ＋ mock，界面老实显示「待接」 | 想从头自己写的 |
| 前端＋契约 | 界面能跑，后端照契约自己写 | 喜欢这个界面、但后端要自己的 |
| 全套 | 前端＋契约＋我们的后端 | 想省事的 |
| 兼容服务 | 前端＋契约＋适配后端，另填自己的合法服务或 key | 通话、外部模型、QQ 等 |
| 完全隐藏 | 普通入口不出现；已有资料保留、以后可恢复 | 当前不需要的人 |

---

## 装了没接通怎么办

**老实说「待接」，不拿假数据冒充。**

已装但缺 key / 缺后端的功能，入口在，点进去是一块说明：缺什么、怎么接。
不会给你编一段通话记录或者假的转录文本。
