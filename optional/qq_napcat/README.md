# QQ · 在岗吗（NapCat 可选包）

让界面里那页「QQ · 在岗吗」活起来：看在不在线、掉线扫码、快速重登。

## 这个包有什么 / 没有什么

| | |
|---|---|
| ✅ `/api/qq/status` | 在线状态（问 NapCat WebUI） |
| ✅ `/api/qq/qr` | 登录二维码 PNG |
| ✅ `/api/qq/restart` | 快速重登 |
| ⏸ 消息桥（QQ 里真聊天） | **没有** —— 那要一个常驻的轮询桥（收消息→喂引擎→回消息），是另一个大组件。契约见下 |
| ⏸ `/api/qq/newseg` | 换新段。依赖消息桥的会话文件，桥没剥所以它也没有 |

## 装

1. 自己跑一个 [NapCat](https://github.com/NapNeko/NapCatQQ)（开源 QQ 协议端），登录你给 AI 用的那个号
2. 配环境变量：`NAPCAT_WEBUI` / `NAPCAT_WEBUI_TOKEN`
3. 在 `core/server.py` 挂上（三行，见 napcat.py 顶部注释），把 `qqStatus` 加进 WIRED

★ **用你自己的小号。** 这等于让一个程序拿着 QQ 登录态，风险自负；
  别用大号，也别拿别人的号。

## 消息桥的契约（想自己写的话）

循环：`收新消息 → 拼上下文交给引擎（同一份记忆注入）→ 把回复发回去 → 落库`。
要点：会话要能「换新段」（清掉引擎的 session 从头开始，但记忆照旧）；
心跳写到一个状态表里，`/api/qq/status` 顺便读它，网页那头才知道桥活着没。
