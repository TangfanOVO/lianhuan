# 连环 · 开源版

一个能长出记忆的 AI 伴侣的家。装在手机上是 PWA，加到主屏就跟原生 app 一样；
数据可以完全留在你自己手机里，不上任何云。

> **现在的状态：能开聊了，还在往外剥。**

> 共读、出门走走那些功能包**还没剥**。
> 下面每一节都会标清楚哪些是真的、哪些还没有。

## 它跟别的聊天壳不一样在哪

**记忆在主链路上，不是插件。** 每次说话之前都会先过一遍记忆：
你是谁、你们之前说过什么、你纠正过它哪里。没有这一层，它就只是个聊天框。

**说话不掉线。** 回复的生死不绑在网页连接上 —— 模型在后台跑到说完，
页面只是观众席。你刷新、切后台、地铁里断网，回来它从头补播，一个字不丢。

**空的时候就是空的。** 新装上那天，记忆是空的，那些页面老实告诉你「还没有东西，
你们才刚认识」。不拿假数据把界面填满装作很热闹。

## 装

```bash
python3 create.py
```

会问你几句，**只把你勾中的复制进去，没勾的根本不下载**：

```
要哪些前端积木？（不装也能用，聊天和记忆是自带的）
  1. 纸感材质   撕边纸 · 胶带 · 票根 · 明信片 · 标本卡      需要：无。纯 CSS
  2. 会动的排法 丝线叠卡 · 纸夹桌面 · 散落成摞，风一吹都会动  需要：无。零依赖
  3. 界面零件   抽屉 · 二级页 · 遮罩 · 底栏                需要：无
  4. 书房       一本书就是一个入口，按下去会被抽出来        需要：无。零依赖
  5. 漂浮物     背景里飘的枫叶/雪/萤火…十种，可多选         需要：无。零依赖
  6. 记忆星图   一个字符＝一条记忆，点画布换形状            需要：无。零依赖
  7. 主页       顶栏·天数·便签·缝线·卡片网格·底栏，零 JS   需要：无
  8. 聊天页     思考链·工具调用·加号十五项·发送键回弹       需要：无。零依赖
  9. 打电话     拨号·对话转写·瞥一眼·那根线·贴耳           需要：无
 10. 通话那条线 谁在说线就往谁那头写                        需要：无。零依赖
 11. 机器人     在不在/电量/头往哪看（只有前端）            需要：一台机器人

桌宠？   不要（默认） / 要一只（我们只指路，不发素材） / 我自己画
引擎？   先不接（回声） / 本机 CLI（用你已有的订阅，不用 key） / API（OpenAI 兼容：DeepSeek、Kimi、智谱、Ollama…）
存哪儿？ SQLite（一个文件，零配置）
```

然后**双击 `start.command`**（macOS / Linux）—— 它会自己建环境、装依赖、起服务、开浏览器。
第一次要一分钟，之后几秒。

要接模型：开起来之后进 **设置 › 功能包 › 引擎**，把接口地址和 key 贴进去就通。
key 存在你自己这台机器的 `data/secrets.json` 里，网页本身不拿它、也不直连任何厂商。
（不想点界面的话，`.env.example` 复制成 `.env` 填进去也行，效果一样。）

```bash
# 或者手动
pip install -r requirements.txt
python -m core.server        # 加 --lan 让同一个 wifi 的手机也能连
```

装完还差什么，`NEXT-STEPS.md` 里按你的选择写清楚了。

**想先看看「满了是什么样」**：`python -m core.seed` 灌一份虚构的演示数据
（人、话、事全是编的，不对应任何真人）。想看真正的空态就 `--clear`。

**没装的功能，界面上不会有那个入口。** 不是灰掉，是根本没有 ——
只装了内核的人，底栏就该是干干净净的自己那几格。

## 只想要其中一块？

可以。前端是按积木拆的，**每层只依赖它下面那层**：

| 你想要 | 拿什么 | 要碰后端吗 |
|---|---|---|
| 这套配色 | 底座 | 不用 |
| 那些纸和胶带的质感 | 底座＋材质 | 不用 |
| 会飘的叠卡 | 底座＋材质＋物理 | 不用 |
| 记忆那套界面 | 再加零件和页面 | 要一份 API 契约（自带 mock） |

详见 [docs/LAYERS.md](docs/LAYERS.md)。每块积木都有自己的 `demo.html`，打开就能看。

## 数据和密钥放哪儿

| 你怎么装 | 数据在哪 | 要密码吗 |
|---|---|---|
| **纯本地**（默认） | 你手机的浏览器里 | **不要**。手机锁屏就是锁 |
| 自建后端 | 你自己的服务器 | **要**。服务开在公网上，知道地址就能进 |

**iOS 不需要上云。** 加到主屏之后数据就留在手机里。

唯一绕不开联网的是跟模型说话（除非你跑本地模型）。所以 key 放哪儿是另一件事：

- **安卓 APK（`android/`）** —— 它是一个**指向你电脑上服务的 WebView 壳**，
  不到 1MB，自己不持有 key、也不能脱离服务独立运行（README 在 `android/` 里，
  实话都写在那）。key 一直待在电脑那份服务的 `data/secrets.json`（0600）
- **网页 / iOS PWA** —— 同理，key 留在你自己跑的服务端，不塞进浏览器
- **绝不做的事**：接管任何消费级订阅的 Cookie。要接订阅只走官方客户端或正规服务端会话。

## 现在有什么 · 还没有什么

| | |
|---|---|
| ✅ 聊天链路 | 流式、分句、思考链、刷新不掉线 |
| ✅ 记忆 | 召回 ＋ 注入 ＋ 落库；中文按 2-gram 匹配 |
| ✅ 人设 | 双方都写，每次说话前交给模型 |
| ✅ 存储 | SQLite，一个文件。导入导出一个 JSON |
| ✅ 引擎 · 本机 | 回声（不接模型，先看界面）· 本机 CLI（用你自己登录的官方客户端） |
| ✅ PWA | manifest ＋ Service Worker ＋ iOS 加主屏 |
| ✅ 前端积木 | 底座 · 纸感材质 · 丝线叠卡 · 界面零件 |
| ✅ 引擎 · API | OpenAI 兼容那一路（DeepSeek / Kimi / 智谱 / 硅基 / OpenAI / 本机 Ollama），贴 key 就通；带工具调用 |
| ✅ AI 有手 | 改自己的签名、写记忆、记心情、发动态、写信、记日历、上架小玩意…（`core/hands.py`） |
| ✅ 外接 MCP | 登记 stdio server，AI 就长出它的工具（跟 Claude 的 `.mcp.json` 同格式） |
| ✅ 选装包 | 记事四件套 · 共读 · 通话（贴 key 即通）· **全双工通话**（能插话）· 颜文字抽屉 · 日历相册 · Obsidian 记忆 · QQ 桥 —— 代码全在包里，**装不装是运行时在 设置 › 功能包 里点的**，不是安装时裁文件 |
| ⏸ 纯浏览器存储 | **还没写**（现在最少也要跑这个薄后端） |
| ✅ 蒸馏（对话→记忆） | 聊够了自己提候选 → **你点头才入库** → 撞车了标出来（不自动合并）→ 常被翻到的自己升层 |
| ⏸ sheet 的三档吸附拖动 | **还没剥**，规格在 `blocks/parts/README.md` |

**发布只从 `create.py` 的产物出发** —— 候选目录里有测试库和密钥（.gitignore 挡着），
直接压缩目录 = 把它们全带走。

**没有的就是没有。** 界面上不会拿假数据冒充能用 ——
没接通的东西**入口照样在**（藏起来等于假装没这回事），只是标着「待接」，
点进去它会说清楚差什么。同理，你选的引擎要是接不通，
「换个脑子」那页会直说现在真正在说话的是哪个，不会挂着一个好看的名字骗你。

还有一些是**故意没带**的：见 [EXCLUDED.md](EXCLUDED.md)，每条都写了为什么。

默认值一律是中性的「伙伴」，改一处就换成你自己的。
