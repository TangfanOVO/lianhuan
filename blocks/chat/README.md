# 聊天页

不是「几个气泡」。是一整页 —— 思考链、工具调用、左下角那颗加号、那排操作键、会回弹的发送键。

| 件 | 是什么 |
|---|---|
| [`chat.css`](chat.css) | 外壳、气泡、思考链抽屉、状态条、加号格子、输入条、底栏 |
| [`chat.js`](chat.js) | 界面这一层。**只认事件，一个网络请求都没有** |
| [`demo.html`](demo.html) | 双击就能看。里头那段对话是编的 |

## 里头有什么

### 一、气泡那一层

- **`|||` 拆段**：库里存的是整段，流式吐的是一句句。`splitSay()` 把 `|||`（或空行）
  拆回一句一个气泡，从历史里拉回来的才跟现场直出长得一样。
- **一轮只有最后一句下面挂那排键**。多少个泡泡，本质上都只是一次回复 ——
  一轮＝一条记录＝一个 `cid`，屏幕上拆成几个泡泡只是断句。`moveActs()` 按 `cid` 分组，
  中间夹了对方的话／时间条／思考链就断组。
- **那排键的间距是不对称的**：`margin:-9px 0 16px 3px`。
  紧贴上面那句（-9），跟下一句拉开（16）。**关键不是「变窄」，是两边不一样** ——
  一样东西离谁近，看的人就认为它是谁的。（原来 -3/7 两边差不多，所以它看着谁都不属于。）
- 时间戳跟在第四颗键后面，不顶到屏幕最右（顶到最右它就不像是这句话的了）；
  当天只报 `21:30`，隔天报 `8月4日 21:30`。两句隔了 8 分钟以上，中间插一条时间。
- 来路标 `ᯇ⩊ᯇ` / `꒪¯꒳¯꒪`：这句是在别处说的，还是打电话时说的。
- 长按 600ms（桌面右键）＝对**任意一条**动手，不只是最新那条。

### 二、思考链

一行 `Thought process` ＋ 一个可拖的 bottom sheet。

- **三档吸附**：`SNAP = [0, 40, 72]`，`CLOSED = 100`（translateY 的百分比）。
- 跟手拖，遮罩透明度跟着高度走 —— 拖到一半就该透一半。
- **甩得快就顺着方向走一档**（`|vel| > 0.6`），慢就吸最近的那一档。
- 顶到头给三分之一的阻尼，不让它翻上去。
- 只有头部可拖（`touch-action:none`），正文照常滚，两者不打架。
- 每条消息带自己的 `data-think`，点开时按 `\n{2,}` 拆成段填进去。

### 三、工具调用

他这轮动过手，屏幕上要看得出来 —— 三样东西：

1. **状态条**一路走：`送出去了… → ✓ 到他那了 → 翻着记忆想你这句… → 正在翻记忆… → 想好了，在写…`
   两张中文表：`TOOL`（进行时，状态条用）和 `TOOL_DID`（过去式，脚注用）。
2. **那颗星**：五个字符 `· ✢ ✶ ✻ ✽` 去五帧回五帧＝十帧，**120ms 一帧，1.2 秒一轮**。
   ★ 先照抄过一套「一列字符 translateY」的做法，结果在手机上只露出小半朵 ——
   容器高度靠一个隐形字符撑，各家行高不一样，窗口就对不上格。
   它本来就是 `step-start`＝**逐帧硬切**，那就干脆逐帧换字符，不靠布局，多大字号都不错位。
   MutationObserver 盯 `hidden`：藏起来就停，不留一个后台定时器空转。
3. **脚注**：`🍁 伙伴翻了翻记忆 · 翻了翻你们的时间线 ›`，点开是一张卡，
   每个动作写着**给出**了什么、**看到**了什么。（原来那排小胶囊只说了「做过」，说不出「做了什么」。）
   ★ 那个名字只写在 `chat.js` 顶上的 `NAME` 常量里（默认 `'伙伴'`），**改这一处就换成你自己的**。

### 四、左下角那颗加号

十五项，四列一格格：

> 翻空间 / 翻碎碎念 / 翻共读 / 贴到空间 / 写日记 / 颜文字 / 照片 / 文件 / 老照片 /
> 一起听 / 说给我听 / 收新消息 / 换新对话 / 哄我睡 / 打电话

「翻」那三条是**把今天的东西翻出来一起看**，不是汇报。
照片和文件是两个入口（相册那个 `accept="image/*"` 手机才会给相册），
挑完**不发**，停在输入框上头等你配一句话。

### 五、输入条

- **发送键回弹**（钉死的那条）：`1 → .9 → 1.06 → 1`，`.41s`。
  连点也要能重放，所以 `remove('pop')` 之后必须 `void offsetWidth` 强制重排再 `add`。
- **回车换行，⌘/Ctrl+回车才发**。（先是「回车发送」，0810 翻案 —— 在手机上打字时，
  回车当发送用会一直把半句话推出去。）
- 他在说的时候，**发送键就是停止键** —— 一个位置两件事，不再多长一颗按钮出来。
- 暂存条：选好的图/文件停在输入框上方。每张有自己的号（`data-k`），
  撤掉一张时其余的**不重播**入场动画（不然就成了抽搐）。
- `font-size:16px` 是硬底线：再小 iOS Safari 一聚焦就自动放大整页。

## 用它

```html
<link rel="stylesheet" href="../base/tokens.css">
<link rel="stylesheet" href="chat.css">
<!-- 页面结构照 demo.html 抄：#chatlog / #chatstat / #ta / .send /
     #thinksheet / #plussheet / #popmenu / #toast -->
<script src="chat.js"></script>
<script>
  const chat = Chat(document, {
    onSend: (text) => myBackend.send(text),   // 你自己的发送
    hooks: {                                  // 加号那十五个入口的落点
      door: (name) => openPage(name),
      pull: (kind) => pullShare(kind),
      pickPhotos, pickFiles, sync, call, lull, voice,
    },
  });
</script>
```

### 接你自己的后端

这一层**只认事件**。把你的流式响应翻译成下面这几种 `type` 喂进 `chat.emit()`，
界面一个字都不用改：

| type | 载荷 | 屏幕上发生什么 |
|---|---|---|
| `sent` | `{text}` | 画出自己那条气泡，状态条「送出去了…」，发送键变停止方块 |
| `recv` | — | 「✓ 到他那了」 |
| `stage` | `{text:'翻记忆'}` | 「翻着记忆想你这句…」，别的值＝「在想…」 |
| `tool` | `{name, detail, done}` | 「正在翻记忆…」／「翻记忆 ✓」 |
| `os` | — | 「想好了，在写…」 |
| `say` | `{text, think, first}` | 一个气泡。`first` 那句底下才挂思考链（一轮一个想法） |
| `meta` | `{tools:[{name,in,out}]}` | 落一条工具脚注 |
| `end` | `{ok}` | 状态条清空，发送键变回箭头 |
| `stop` `newseg` `resume` `room` | — | 停下了／换了新的一段／线接回去了／换了房间 |

`Chat.play(chat, turn)` 是 demo 用的**假事件源**：把一段编好的对话按真节奏喂进去。
真接后端时删掉它就行。

## demo 里那段对话是编的

`demo.html` 里的对话、思考链正文、两条工具记录，**全部是为了演示编出来的**。
这页不连任何模型、不读任何记忆、不发一个网络请求；加号里那十五个入口点了只会弹一句
「预览页不接真入口」。

## 零依赖 · 零网络

`chat.js` 里没有 `fetch`、没有 WebSocket、没有任何 import。
