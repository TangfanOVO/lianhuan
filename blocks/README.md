# 前端积木

前端是按积木拆的，**每层只依赖它下面那层，不依赖上面**。所以你可以只拿走一层。

```
base     token · 两套配色（纸／夜）· 一键换色 · 前景色对比度自动算 · 字 · 动效规格
 └ paper   撕边纸 · 格纹胶带 · 票根 · 明信片 · 标本卡 · 小册标签        ← 纯 CSS
    └ physics  丝线叠卡（会飘的那个）· 水面待机 · 字云            ← 丝线已剥
       └ parts   二级页 · 抽屉 · sheet · 全局搜索 · 热力图月历            （还没剥）
          └ pages  聊天页 · 记忆页 · 书房 …                            （还没剥）
```

| 你想要 | 拿哪几层 | 要碰后端吗 |
|---|---|---|
| 这套配色和手感 | `base` | 不用 |
| 那些纸和胶带的质感 | `base` ＋ `paper` | 不用 |
| 会飘的叠卡 | `base` ＋ `paper` ＋ `physics` | 不用 |
| 整套界面 | 全部 ＋ 一份 API 契约 | 要（自带 mock） |

## 命名

每块一个前缀，互不打架：`paper` → `.pp-`。
底座用 CSS 变量，不占类名。

## 名字（角色名不写死在积木里）

这套积木原本长在一个私人的 AI 伴侣应用里，那边的伙伴有名字。剥出来的时候
**名字一个都没带进代码**：凡是界面上要显示名字的地方（通话里的说话方标签、
demo 的对话行……），文件顶上都有一个 `NAME` 常量，默认值是中性的 `'伙伴'`。

```js
const NAME = '伙伴';   // ← 改这一处，全文件就换成你自己的名字
```

说话方／听话方是**成对**出现的，两边都走常量，别只改一半。
来历见仓库根目录的 [UPSTREAM.md](../UPSTREAM.md)。

## demo 里的字全是编的

每个 `demo.html` 里的对话、记忆、书名、人名都是**专门写的虚构内容**，
不对应任何真人 —— 页面上也写着这一句。想看空态就把数据数组清空。

## 亮色暗色

全在底座里。**你不用写第二套** —— 积木只用变量，不写死颜色。
底座三处都定义了暗色（系统偏好 / 手动切暗 / 手动切亮），手动切的能压过系统偏好。
