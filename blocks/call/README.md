# 打电话

**整页**，不是一根线。给对面那位打电话的那一页：拨号／来电／接通中／在听／在想／在说／挂断，
八个相位、两张皮、一条打字条、一块贴耳黑屏，外加中间那条线（那条线是隔壁 [`../thread`](../thread) 那一块）。

一句话（原项目那份自己写的）：**线是一条线。谁在说线就往谁那头写；伙伴在想的时候，
线在那一头一笔写出枫叶，写完继续往右，走远了尾巴从左边一点点拆掉。一开口，尾巴追着头把整条拆干净。**

> ★ 这一页**不申请麦克风、不连任何服务、不伪造接通**。demo 里那通电话是**编的剧本** ——
> 那几句话谁都没说过。要接真后端，走文件末尾的 `window.__call`。

| | |
|---|---|
| [`call.css`](call.css) | 整页的样子。照搬原项目 `redesign/call.html` 第 47–296 行 |
| [`call.js`](call.js) | 相位机、逐字落下、打断墨点、换皮、打字条、接线口 `window.__call` |
| [`demo.html`](demo.html) | 双击就能开。整页 DOM 照搬原项目 298–403 行，外加一条 demo 自己的小条 |

## 用

```html
<link rel="stylesheet" href="../base/tokens.css">
<link rel="stylesheet" href="../thread/thread.css">
<link rel="stylesheet" href="call.css">

<!-- DOM 照 demo.html 那一份搬，id 是接口的一部分（call.js 按 id 找元素） -->

<script src="../base/crest.js"></script>
<script src="../thread/thread.js"></script>
<script src="call.js"></script>
```

三个 `<script>` 的**顺序是硬的**：`crest.js` 给那片枫叶，`thread.js` 给中间那条线，
`call.js` 最后接上去。缺前两个不会报错，只是没有家徽、没有线。

## 这一页上有什么

- **八个相位**：`idle` / `incoming` / `ringing` / `connecting` / `listening` / `thinking` /
  `speaking` / `ended`。顶栏那颗点跟着相位变色变大；**「在想」的时候它让位给一颗星** ——
  五个字符 `· ✢ ✶ ✻ ✽` 排一列上下滚，`step-start` 一格一格跳，不是滑。
- **皮一 · 对话转写**：左边是伙伴那一侧、右边是用户那一侧。伙伴的话**逐字落下**（`drop .34s`），
  被打断就停在那个字上、末尾留一个**墨点**不消失。往上的旧话按 age 淡出并缩字
  （`0→1 / 1,2→.74 / 3→.46`，字号 `16→14.5→13.5`），顶上一道 mask 渐隐。
  能往上翻 40 行 —— 翻上去了新字就不抢位置，翻回底部自动恢复贴底。
  说英文时中文转录跟在下面一行小字；`伙伴 · 想了 3.4s` 那个标签在名字后面。
  设置里可以切**硬双栏**（`setLayout('columns')`）：每句显式占一行，中间一道缝，
  不然一侧的上一句和另一侧的下一句会挤进同一行、时间顺序就丢了。
- **皮二 · 瞥一眼**：贴耳拿开的那一下要能一眼读完。40px 的相位大字 ＋ 19px 的最后一句，
  长段落自己滚（`max-height:46vh`），滚条不露脸。两张皮左右划，或者点底下那两个点。
- **打字条**：不方便说话时的另一张嘴。输入框 `16px` 是**硬的**（iOS 一聚焦就放大整页）；
  发送键是**描边**的 44px 圆 —— 全屏唯一的实心枫叶红留给挂断／接听。
- **底下那一排**：静音（按下去有一道斜杠）、**72px 实心枫叶红主键**（待机是拨号图标，
  接通后翻成挂断）、贴耳。来电时主键降成描边（＝拒接）往左让 52px，接听键从右边 52px 处推出来。
- **贴耳黑屏**：`#07090c` 铺满，中间一条 132px 的线在呼吸。
  贴着脸的时候不许有亮的东西 —— 那行提示 3 秒后自己沉进黑里。
- **Motion**：`drop` / `rise` / `breathe` / `sink` / `sendpop` / `enterCall` / `crestLand` /
  `ringBeat` / `sinkOut`，`prefers-reduced-motion` 下整套降级（逐字落下直接落定）。

## 接线口 `window.__call`

界面**只吃这些调用**，自己不去问任何人。方法名跟原项目一个字不差 —— 宿主接真后端时照这个接。

| | |
|---|---|
| `setPhase(name)` | 换相位。八个名字见上 |
| `pushMine(text, alt, ms)` | 伙伴那一侧说的，逐字。`alt`＝下面那行小字，`ms`＝「想了 x.xs」 |
| `pushHers(text, alt)` | 用户说的，整句上屏（识别本来就是说完才回来的） |
| `hersLive(text)` | 用户说话时逐字回屏：识别是滚动重发全句的，所以**原地改**最后一行，不往下堆 |
| `hersDone(text, ms)` | 这一句识别定稿了 |
| `progress(shown)` | 逐字驱动。接了 TTS 就按播放进度调它，别用文件里那个定速打字机 |
| `finishMine()` | 播完了把这句补齐，别让它停在半路 |
| `setAlt(text)` | 翻译是**后到**的（说完才翻），到了补在最后那句底下 |
| `barge()` | 用户一开口：掐掉回放、跳回 `listening` |
| `setLevel(v)` | 0～1，喂给那条线。不喂就走合成包络 |
| `incoming()` | 对面打过来了（本机打出去是 `setPhase('ringing')`） |
| `setTheme(t)` | `light` / `dark` |
| `setLayout(l)` | `stream` / `columns`（硬双栏） |

`window.__phase` 一直是当前相位，嵌进宿主时靠它兜底知道电话结束没有。

## 从原项目搬过来时减掉了什么

原项目那份是**接了真后端**的整页（`redesign/call.html`，1399 行）。这一块是它的前端那一半，
下面这几段**没搬**，每一段都不是因为「看起来可以更好」，是因为预览页不许做那件事：

| 没搬的 | 原项目在哪 | 为什么 |
|---|---|---|
| 真接线 `WIRE` | 1259–1396 | WebSocket 接端到端语音。**积木不发任何请求** |
| 麦克风 | 576–604 | `getUserMedia`。**这一页不申请麦克风**。半打断（VAD）跟着它一起没了；`barge()` 作为接口还在，宿主自己判断什么时候叫 |
| 重演模式 ＋ 那根拉杆 | 899–1134 / CSS 96–107 | 要 `fetch` 一段旧通话的录音回来 |
| 嵌进宿主 `EMBED` | 872–897 | 往父窗口 `postMessage`。预览站里没有那个父窗口 |

因为这几段不在，`DEMO` 就留在 `true` —— 那正是原项目给「在浏览器里看」留的那条分支，
主键按下去走的是 `script()` 那段编好的剧本。**接你自己的后端时把它改成 `false`**，
界面就只吃 `window.__call`，一个字也不自己演。

另外三处是机械替换，不是重画：

- **token**：原项目在文件开头自己写了一份 `:root`（16–45 行），这儿用底座 `../base/tokens.css`。
  色名一样（`--maple` 在底座里桥到 `--accent`），所以选择器和值原文可用。
  只有 `--hang-cast`（主键那圈投影）底座里没有，把原项目那四处**原值**搬进了 `call.css` 顶上。
- **那片枫叶**：原项目是把 path 直接写在 `#crest` 里的。这儿从 [`../base/crest.js`](../base/crest.js)
  的 `Crest.def('maple')` 取 —— 那是**同一份** path（786 字节逐字相同），
  中间那条线读的也是它。全仓库只有这一片枫叶，要换就改那一处。
  （Font Awesome Free 6 · canadian-maple-leaf · Icons CC BY 4.0，署名见 `UPSTREAM.md`。）
- **`.threadwrap{height:76px}`** 不在 `call.css` 里写第二份 —— 它在
  [`../thread/thread.css`](../thread/thread.css)，值一样。一个数两处写，早晚漂开。

还有一处一个字符的改动：原项目 `@keyframes sink` 写的是单帧 `to{…}`（合法，起始帧隐含＝当前色），
积木包的 css 自检要求每个 `@keyframes` 至少有首尾两帧（防文件被截断），
所以把那个隐含的起点写明成 `from{color:#8b7d73}` —— `#8b7d73` 就是 `.earhint` 自己的原色，效果一模一样。

## demo 里那通电话

`demo.html` 顶上那条小条是 **demo 自己的**，真界面一行都没改（它只调 `window.__call`）：
八个相位手动切、「演一遍」跑一遍剧本、「硬双栏」切排法、「收起」让开。

剧本里那四句话（用户先开口 → 伙伴说到一半被打断 → 用户接上 → 伙伴用英文收尾、下面跟一行中文转录）
**全是编的**。原项目那份用的是真的聊天记录，开源这一份一个字都没带过来。
「回连环」那条退路是留给宿主自己首页的，预览里它不跳。

## 名字

界面上所有露名字的地方（待机页标题、来电提示、转写标签、瞥一眼那句大字）都引 `call.js`
**顶上那两个常量** —— 代码里没有第二处写死的名字：

```js
const NAME = '伙伴';   /* 对面那一侧（AI）在界面上叫什么 */
const ME   = '我';     /* 这一侧（用户）在转写标签里叫什么 */
```

默认就是中性的「伙伴」，改这两行整页跟着变（`给伙伴打电话` / `伙伴打过来了` /
`伙伴在说` / 转写标签 `伙伴 · 想了 3.4s` 和 `我 · 听懂 0.8s`）。
`demo.html` 里另有**两处静态文案** —— 顶栏 `.who` 和打字条 placeholder，
那是宿主自己的 DOM，换名字时跟着一起改（两处都在旁边留了注释）。

这一块的原型出自一个私人伴侣应用，那边角色叫什么、这份代码从哪儿来，见仓库根的
[`UPSTREAM.md`](../../UPSTREAM.md)。

## 换肤

颜色全从 CSS 变量读，宿主改了变量之后叫一次 `__call.setTheme('dark'|'light')`
（它会顺手让那条线重读 `--ink` / `--thread` / `--maple`）。
明暗两套都在 `../base/tokens.css` 里，手动切的那套压过系统偏好。
